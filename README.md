# Codeforces Solutions

Just my Codeforces solutions, all in C++. Mostly Div 2/3 A and B problems for now, will keep adding more as I solve them.

Each file is named after the problem (like `1A.cpp`, `50A.cpp`, `617A.cpp`) matching the Codeforces problem number/letter, so it's easy to find whatever you're looking for.

## Why this repo exists

Started this to track my CP progress and have a backup of solutions I can look back on. Also helps when I forget how I solved something and want to revisit the logic later.

## Structure

No folders or fancy organization right now — everything's flat in the root. Might split into difficulty-based folders later if this grows.

## Notes

- Solutions aren't always the most optimized, they're what got AC at the time
- Some might have leftover debug code or comments from when I was working through the problem
- Will clean up / refactor some of the older ones eventually

Feel free to look through if it's useful, and let me know if you spot a better approach for any of these.
